## Scope

Changes since v0.8.9:

- Prevent duplicate session-metadata refresh workers from accumulating after slow Git metadata work exceeds a request deadline.
- Keep metadata refresh ownership single-flight and let reconnect resynchronization use ordinary metadata reads instead of repeatedly forcing new workers.
- Restore responsive Tabs switching by removing the backend refresh amplification that made the browser wait behind redundant metadata work.

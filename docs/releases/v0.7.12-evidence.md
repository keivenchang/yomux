# v0.7.12

Landing record for annotated release `v0.7.12`. The final release commit is the object resolved by `v0.7.12^{commit}`; the exact pushed SHA is recorded in the release handoff after the tag and origin refs are verified.

## Shipped scope

- YO!stats health reads no longer wait behind transcript discovery, parsing, or legacy repair. Transcript health reads one immutable committed generation, while a new active roster transcript is scheduled ahead of historical repair backlog so Agents, Tokens, and Cost populate from current work.
- File watching now reports the bridge's explicit serving state. A verified running watchd process waiting for its first bridge revision stays `starting` instead of being retained as `degraded / service_unhealthy`; real transport failures, recorded failures, fallback failures, and unhealthy serving states still alert.
- The top System triangle and Daemons roster use one green/yellow/red reduction. One accepted healthy revision immediately replaces a stale warning, and the healthy triangle remains visible with a low-opacity green glyph and border, no glow, and stronger yellow/red states.
- The release also includes the post-0.7.11 local-service lifetime and process-identity ownership work, Stats range-cost reconciliation fixes, statsd ring-invalidation reduction, and client-event broker lock reduction already landed on local `main`.

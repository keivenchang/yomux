# v0.7.27

Landing record for the global release containing the Preferences reorganization, startup gate, OpenCode token attribution, and OpenCode touch-scroll fixes added after `v0.7.26`. The exact tested subject SHA and final annotated tag target are recorded after the release commit and tag are created.

## Shipped scope

- Preferences settings are reorganized into the new shared settings surface with synchronized locale catalogs, runtime state, and browser coverage.
- Startup capacity checks report schedulable affinity and cgroup limits, use measured Linux pressure and throttling signals, classify configuration and measurement failures separately, and protect restart locks with process and boot identity.
- OpenCode token collection resolves exact session IDs from process arguments or a uniquely matching terminal title, preserves fail-closed behavior for ambiguous titles, and ignores stale directory hints when an explicit session ID is present.
- OpenCode iPad touch scrolling preserves fractional finger movement and sends native line-wise message navigation so the conversation moves without moving the prompt or footer.

## Verification

- Focused OpenCode and startup suites passed during release preparation.
- The canonical `python3 tools/check.py` run was attempted after the Preferences merge. Its non-browser lane reported shared-worktree and host-process failures; those results remain part of the release boundary and are not counted as a green full gate.

## Release boundary

Both runtime version owners report `YOLOMUX_VERSION = "0.7.27"` in the release commit. The final release commit is the annotated tag target `v0.7.27^{commit}` after landing on `main`.

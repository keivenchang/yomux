## Evidence rules retained from the source

- Gate rows require the exact immutable candidate and the same collected tests. Missing declared test dependencies are failures, not accepted skips; there must be zero failed tests, errors, collection errors, and XPASS results.
- Five-run convergence evidence requires five successful runs in each named environment. One focused pass or an older-SHA run does not satisfy row 6.
- The directory-FD soak is process-wide. It counts every directory descriptor held by the exact served PID, requires a complete 30-minute terminal sample, and does not discard co-tenant descriptors from the total.
- From candidate launch through terminal acceptance, the served worktree stays at one recorded SHA. Reading `/proc/<pid>/cwd` after that worktree moves does not identify the code image loaded by the running process.
- Retries, serialization, relaxed assertions, wider fixed ceilings, or unexplained skips do not turn a red gate into release evidence.

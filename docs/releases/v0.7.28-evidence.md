# v0.7.28

Landing record for the global release containing the combined work prepared after `v0.7.26`. The exact tested subject SHA and final annotated tag target are recorded after the release commit and tag are created.

## Shipped scope

- Preferences settings are reorganized into the shared settings surface with synchronized locale catalogs, runtime state, and browser coverage.
- Startup capacity checks use schedulable CPU affinity and measured Linux pressure and throttling signals, classify configuration and measurement failures separately, and protect restart locks with process and boot identity.
- OpenCode token collection resolves explicit session IDs or uniquely matching terminal titles, handles quoted titles, preserves fail-closed behavior for ambiguous titles, and ignores stale directory hints when an explicit session ID is present.
- OpenCode iPad touch scrolling preserves fractional finger movement and sends native line-wise message navigation so the conversation moves without moving the prompt or footer.
- Test isolation keeps the documented Linux live-port range protected and relocates overlong local-service socket paths to a bounded private transport root.

## Verification

- Focused OpenCode, session, startup, isolation, local-service, and product-root suites passed with 443 tests passed and 1 skipped.
- The browser boot suite passed with 7 tests passed.
- The Node layout suite passed with 20 shards passed and 0 failed.
- The architecture budget, text-shape assertion, static-build, Python compilation, syntax, and whitespace checks passed after the final fixes.
- The full canonical gate was run on the clean release commit. Static checks, end-to-end tests, Node layout, Python compilation, syntax, whitespace, and seven-unit exclusive certification passed. The non-browser lane reported five unrelated existing regressions, and the broad browser lane reported five existing regressions plus two errors; the release is not described as full-gate green.

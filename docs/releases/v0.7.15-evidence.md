# v0.7.15

Landing record for annotated release `v0.7.15`. The final release commit is the object resolved by `v0.7.15^{commit}`; the exact pushed SHA is recorded in the release handoff after the tag and origin refs are verified.

## Shipped scope

- The tmux signal watcher now exposes a watcher-owned condition for lifecycle convergence. Tests and other in-process owners can wait for the exact `attached` publication instead of treating an externally visible tmux client row as proof that YOLOmux has finished process-claim publication and published healthy state.
- Spawning and publishing a new control-client handle is fenced against `stop()`. A stop request can no longer return while a just-spawned child remains invisible to the watcher, and a watcher that was already stopped does not start another child.
- A stopped control client immediately leaves the healthy `attached` state. The worker cannot publish `attached` after stop wins, and final cleanup keeps the status at `exited` after terminating the owned process.
- Roster and context revisions that arrive while an older session-metadata request is finishing retain one follow-up read against that exact request. The browser now consumes the cache generation published by the event instead of joining bytes requested before the revision and leaving the UI partially converged.
- Terminal connection refresh no longer clears an active layout refusal before the topbar paints it. Red and yellow layout messages keep their shared status ownership until their normal paint or retirement transition, and publishing a layout status removes the earlier terminal-connection tooltip so hover text cannot contradict the visible warning.
- The authenticated route sweep exercises create-session refusal through an unavailable explicit terminal instead of an unknown agent name, because unknown names intentionally fall back to Claude. The sweep now proves that it leaves only its original private tmux session, and accepted filesystem operations receive the product Git deadline before fixture teardown.

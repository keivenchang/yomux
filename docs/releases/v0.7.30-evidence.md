# YOLOmux 0.7.30 Evidence

Release commit: `v0.7.30^{commit}`.

This release hardens editor saves, conflict recovery, queued-operation journal recovery, and OpenCode runtime support. Saves for one file are serialized across duplicate editor panels, preserve edits made during an in-flight write, carry accepted file identity into queued writes, migrate across file renames, and keep conflict overwrite actionable. The terminal routes OpenCode touch scrolling through the native application input path, Linux process identity accepts an in-use replaced OpenCode executable, and live YO!stats token attribution resumes for OpenCode panes. The release also bounds concurrent lease cleanup, removes raw terminal text from recent-agent summaries, preserves Claude sibling transcript identity, and fixes login-notice HTML escaping.

The release includes focused editor, journal, transcript, statistics, authentication, session, terminal, and OpenCode tests; all 20 Node layout shards; static asset validation; architecture-budget validation; and `git diff --check`. The canonical gate was run after the release candidate was rebased onto local `main`. The functional lanes still report the existing CodeMirror vendor warning `Measure loop restarted more than 5 times` during browser teardown, and one browser Finder test remains sensitive to the expanded Git-history page size. Host qualification also refused one certification unit because of measured I/O-stall pressure. These are recorded as gate limitations, not as passing certification.

The tested release candidate was based on local `main` commit `5a258c7542747332348f7dec7019eb95d20324c8` before the version bump. The final release commit is the commit containing this page and the matching `0.7.30` literals; the final annotated tag must point to `v0.7.30^{commit}` after the release commit lands on `main`.

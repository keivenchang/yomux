# YOLOmux 0.8.0 Evidence

This release carries the source-backed Markdown ViewEditor and its ProseMirror editing, synchronization, round-trip, image paste/upload/rendering, and safe-fallback behavior. It also includes the Dockview layout and drag/drop hardening, corrected Linux startup capacity admission, Git history refresh recovery, escaped-newline rendering in commit details, and the associated backend, frontend, and browser coverage.

Both runtime version owners report `YOLOMUX_VERSION = "0.8.0"` in the release commit. The release is intended to ship as annotated `v0.8.0`; after publication, the immutable release target is `v0.8.0^{commit}` and must match pushed `origin/main`.

Verification for this candidate includes the rebuilt static bundle, static-build freshness check, JavaScript syntax validation, focused Git-history/ViewEditor/browser-independent tests, and the canonical release gate. Live port 7220 was restarted from this worktree and reported `/healthz -> 200`; unauthenticated `/api/ping` returned `401`.

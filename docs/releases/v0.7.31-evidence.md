# v0.7.31

Landing record for the YO!stats and YO!cost rewrite.

## Shipped scope

- YO!cost uses one server-owned report with Cost by Model followed by Cost by Agent.
- Agent rows own expandable source-attribution details, and the browser preserves expanded rows during live refreshes.
- Routed `switchyard/openai/...` and `inferencehub` OpenAI model identities resolve through the reviewed pricing catalog.
- Stats storage and ring payloads use the schema 9/version 25 contract, with explicit schema 8 migration and invalidation handling.

## Verification

- Focused stats, migration, protocol, materializer, service, storage, usage, client, and application tests passed before landing.
- The pricing regression for routed Switchyard and Inference Hub OpenAI identities passed.
- The Node stats panel and current-stats user-interface suites passed after the final bundle rebuild.
- The full repository gate was run before landing. It reported existing environment and resource-sensitive failures and refused exact-SHA certification because the checkout was dirty at the time of that run.

## Scope

Changes since v0.8.7:

- Stabilize agent-token coverage epochs and route token collection through the stats database owner.
- Guard metadata refreshes across server epochs so a replacement server can publish its own generations without inheriting stale client state.
- Reduce Tabs roster refresh latency by converging external tmux renames through compact roster updates and preserving stable tab identity across delayed metadata responses.
- Keep ProseMirror ViewEditor initialization from misclassifying an incomplete literal HTML fragment such as `</th` when a later Markdown line contains a closing `>`; this preserves the source in the ViewEditor instead of entering the expensive failure/fallback repaint path.

# v0.7.19

Landing record for annotated release `v0.7.19`. The final release commit is the object resolved by `v0.7.19^{commit}` after this record, the version owners, and the rebuilt bundle are committed, landed on `main`, and tagged. The release handoff records the exact peeled tag target and the pushed `origin/main` SHA.

## Shipped scope

- Reopening an already-open file through a canonical path or resolved alias preserves that tab's Edit, Preview, or Diff mode. An explicit mode action remains the only mode-changing action.
- Terminal file actions create their tab and direct descriptor-authorized base read before optional Git enrichment finishes.
- Jobd uses independently replaceable one-worker slots. A deadline-backstop quarantine fences a late predecessor result, retains no more than two unreaped predecessors across the daemon, and leaves healthy sibling slots running after a broken worker or failed submission.

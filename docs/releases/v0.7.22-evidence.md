# v0.7.22

Landing record for annotated release `v0.7.22`. The final release commit is the object resolved by `v0.7.22^{commit}` after this record and both version owners are committed, landed on `main`, and tagged. The release handoff records the exact peeled tag target and pushed `origin/main` SHA.

## Shipped scope

- The check runner no longer offers the redundant `pytest-unit` and `pytest-socket` aliases. Their covered tests remain in the default pytest and E2E lanes.
- `--serial-lanes` runs functional lanes one at a time without changing their normal pytest worker counts. The existing `--serial` mode continues to run with one worker per pytest lane.

- `python3 -m pytest tests/test_architecture_budgets.py -p no:randomly -q` passed 26 tests.

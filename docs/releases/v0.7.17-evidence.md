# v0.7.17

Landing record for annotated release `v0.7.17`. The tested candidate is `e89920a4dfa77fabb062a90b54cf9987d4eb42e4` on `release/v0.7.17-landing`, rebased onto local `main` after `v0.7.16^{commit}`. The final release commit is the object resolved by `v0.7.17^{commit}` after this documentation-only correction is folded into the branch and the tag is created; the exact pushed SHA is recorded in the release handoff after both origin refs are verified.

## Shipped scope

- YO!stats now rebuilds bounded exact time-series data in batches, retains a fixed serving ring, and uses bounded accumulation rather than holding whole sample lists.
- The statistics service exposes `/livez` and authenticated `/readyz` health contracts, records stream-boundary evidence when a stream goes quiet, and publishes a resource projection for its service row.
- Batched persistence is guarded and disabled by default until its generation-key collision is resolved. The shipped code retains acknowledged facts on conflict and retries a failed flush that cannot name an offender.
- The gate now classifies a YO!stats stall, owns inherited process-capture bookkeeping while leaving health requests concurrent, and measures cost resolution without treating SQLite WAL/page-accounting jitter as a product-cost increase.
- Editor and gate-stability repairs from the composed release branch are included. The parallel right-click/editor-open-options work is not included in this release record.

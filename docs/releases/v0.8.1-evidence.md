# YOLOmux 0.8.1 Evidence

This release publishes the ProseMirror Markdown ViewEditor improvements: preserved hidden Markdown comments, visible literal unknown XML-like tags, superscript support, authenticated first-load image rendering, link context-menu actions, semantic split scrolling across hidden comments and tall media, and top-quarter source/rendered focus. It also includes the associated Dockview, Finder, startup-capacity, Git-history, and test-harness fixes.

Both runtime version owners report `YOLOMUX_VERSION = "0.8.1"`. The final annotated tag is `v0.8.1`, and its immutable target must equal `v0.8.1^{commit}` on the released `origin/main` commit.

Focused Node, E2E, non-browser, gate-serial, static-build, syntax, and git-diff checks passed. The full browser lane still has known environmental/fixture failures under host load; these are recorded in the release handoff rather than hidden.

# v0.7.18

Landing record for annotated release `v0.7.18`. The final release commit is the object resolved by `v0.7.18^{commit}` after this record, the version owners, and the rebuilt bundle are committed, landed on `main`, and tagged. The exact pushed SHA is recorded in the release handoff after both origin refs are verified.

## Shipped scope

- A terminal file action creates its context menu and editor tab immediately. The tab owns a direct, descriptor-authorized base read and displays `Loading...` until bytes or a typed file state arrive.
- Base file reads and raw media reads bypass jobd artifacts, receipt polling, and the startup refresh governor. Optional Git metadata, Blame, and Diff remain deferred work and never block initial content paint.
- Terminal candidate resolution is bounded, coalesced, and scoped to at most eight context-derived paths. Passive terminal decoration no longer probes the filesystem.
- A direct missing-file response preserves the typed `path_not_found` result without manufacturing a jobd operation or receipt.

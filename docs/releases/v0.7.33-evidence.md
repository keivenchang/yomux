# YOLOmux 0.7.33 Evidence

This release keeps OpenCode usage collection available after a session exceeds the normal full-read bound. The collector passes its durable event-revision cursor to a larger bounded incremental read, skips unchanged step-finish records, emits new records, preserves cumulative-counter validation for unanchored sessions, and accepts hashed event IDs for long identifiers.

Verification included 438 stats tests, 312 mock and launch tests, 68 core URL tests, 67 terminal URL tests, 66 settings tests, and 216 asynchronous layout tests. The live Luna OpenCode database read returned `OpenCodeReadSuccess` and included `switchyard/openai/gpt-5.6-luna`.

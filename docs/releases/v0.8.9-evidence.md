- Keep Markdown ViewEditor initialization valid across tab switches and prevent ViewEditor DOM feedback loops that could trigger the expensive error and fallback path.
- Render Mermaid previews read-only and repair their preview interaction path.
- Show the backend runtime identity with the release version in the top-left version hover.
- Remove retired follower/election wording and simplify local background scheduling, exclusive instance ownership, bounded refresh state, and shutdown cleanup.
- Ignore local crash dumps so a large `core` file cannot appear as a release candidate change.

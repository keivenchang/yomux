# YOLOmux 0.8.2 Evidence

This release carries direct authenticated raw-file loading for local Markdown images in both the ordinary preview and ProseMirror ViewEditor paths. It removes the unnecessary Blob/object-URL indirection while preserving relative-path resolution and image failure handling. It also removes passive terminal file-reference filesystem resolution during terminal repaint, scroll, resize, and output, reducing filesystem request amplification without removing explicit file actions.

Both runtime version owners report `YOLOMUX_VERSION = "0.8.2"`. The final annotated tag is `v0.8.2`, and its immutable target must equal `v0.8.2^{commit}` on the released `origin/main` commit.

Focused ProseMirror, layout, static-build, syntax, architecture-budget, and diff checks passed. The complete repository gate was attempted: 19,025 non-browser tests passed, while the shared overloaded host prevented certification and the browser/E2E lanes had broad environment failures. Those limitations are part of this release record.

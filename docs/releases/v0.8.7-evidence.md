## Scope

Changes since v0.8.6:

- Isolate server product roots so each managed server owns its runtime, state, cache, and service lifecycle without cross-port collisions.
- Refine search and ViewEditor theme behavior, including the light editor scheme and two-state preview/theme transition.
- Preserve rich ViewEditor content and asynchronous image extraction for paste and terminal file-drop paths.
- Coalesce watch-driven metadata refreshes and preserve one metadata refresh flight across watcher reconnects.
- Move token collection into statsd and route the compatibility test adapter through the shared collector so statsd is the production owner.
- Improve editor and application theme isolation and clean metadata formatting.
- Add durable operation-terminal replay repair with lifecycle-owned cleanup and bounded retry.
- Preserve editor/ViewEditor synchronization, safe HTML, task-list, Mermaid, media, clipboard, and Markdown image behavior in the current browser contract.
- Publish metadata and status generations together so forced refreshes and new-session roster consumers converge.
- Enforce exclusive product-root ownership, local-owner session-file cache delivery, and process-level lease rejection.
- Keep filesystem operation receipts in the browser teardown barrier and prevent duplicate session-files completion application.
- Unify Dockview drag coordinate classification and preview/commit ownership for headers, pane content, chrome, and root edges.

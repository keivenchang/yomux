Fix (`10_core_utils.js`): the group walk now also stitches hanging-indent URL continuations — backward sweep extends past an indented row whose previous row's tail is an unterminated url token, and the forward build, while the joined text still ends mid-URL, pulls in following indented URL-valid rows (indent stripped for matching, recorded so the underline maps to the row's REAL columns). Gated tightly (only EXTENDS a url token running off the right edge; `terminalTailIsUnterminatedUrl` + a leading-whitespace-then-URL-char shape check) so prose and adjacent independent lines are never merged. The whole URL is now ONE clickable link, underlined across both rows, active from either row. Existing true-soft-wrap behavior preserved. Node tests cover the hard-wrap stitch (both query rows + the no-merge prompt row) and the prose-not-merged / standalone-indented-URL cases.

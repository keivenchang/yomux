# Working agent indicator: static symbol + glowing green ball, and stop rotating the YO marker

- Final design (after iterating through a symbol opacity-pulse and a symbol<->ball alternate, both of which the user rejected): every Claude/Codex status indicator shows its agent symbol STATIC with a SEPARATE glowing ball beside it — `[symbol][ball]`, side by side — on dock pane tabs, the tmux sub-window bar, Tabber rows, and Info Pane buttons. Working uses a quieter green ball, attention uses a stronger red ball, and cooldown uses a stronger yellow ball; all three glow via the existing `attention-ring-fade` status-dot animation. `--active` keeps the `agent-symbol-glow-cadence` symbol glow because it is current-window state, not a status ball. Focused Selenium verifies static symbol opacity/animation, a working-tone dot animating `attention-ring-fade`, wrapper `display:flex`, and no YO rotation.
- Implementation (`static_src/css/yolomux/20_sessions_popovers.css`, `static_src/js/yolomux/35_agent_window_activity.js`): `agentWindowStatusDotHtml` now renders the dot for the working state (not just attention/cooldown); working symbols no longer get `heartbeat-pulse` (stay static); the old grid/alternate rules and keyframes are gone so status indicators keep base inline-flex. The activity ball is sized from `--agent-window-icon-size` (not the surrounding font) so it is the same size on every surface — before, the dock-tab ball (11.4px) and Tabber ball (10.4px) came out different sizes.
- Stopped the YO marker rotating to signal working (the glowing ball does that now): removed the `yolo-marker-rotate` animation from `.session-yolo-marker.working` and from `.about-brand-yo` (About modal); the sign-in `brand-yolo` already had no rotation. Differ loading no longer uses a YO spinner. YO!agent then retained transient spinner markers, which were subsequently removed in favor of the shared moving ellipsis.
- Also from this investigation, kept: the shared working predicate so the indicator renders whenever `sessionYoloIsWorking` (incl. the `screen.key==='working'` proxy, the original "Tab 7 YO'ing but nothing shows" case) — `sessionWorkingAgentWindowForTab` in `60_popovers_tabs.js`, used by dock tab/Tabber/window bar.
- Tests (`tests/test_browser_dockview.py`, `tests/test_browser_layout.py`, `tests/tabber.test.js`, `tests/editor_preview.test.js`, `tests/share_theme.test.js`): renamed the working-state tests to the static-symbol + glowing-ball contract, added split-layout coverage for working/attention/cooldown across dock tabs / Tabber / Info Pane buttons, added `test_tabber_live_rows_use_custom_hover_without_native_titles`, and kept `test_platform_controls_use_pc_glyphs` for static YO. Spec updated in `docs/specs/GUI.md`. Work is on 8001 only this round — NOT landed on main/prod. Full `tools/check.py` still fails in the known live-tmux `test_app.py` area (now 7 failures with unexpected `%16`) and two parallel browser Dockview wait timeouts that pass serially; focused Selenium/Node tests pass.

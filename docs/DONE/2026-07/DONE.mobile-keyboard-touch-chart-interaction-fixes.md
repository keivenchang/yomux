- Completed and removed `DOIT.login-rate-limiting.md` (layered login throttling by account and network). Every password path — the browser `POST /login` form and HTTP Basic — is now throttled BEFORE the PBKDF2 verifier through one shared owner (`yolomux_lib/login_rate_limit.py`), so brute force, credential stuffing, and password spraying are bounded and a blocked attempt costs no password hash. Two O(1) primitives: token buckets for four hierarchical network scopes (exact `/32`·`/128`, nearby `/24`·`/64`, broad `/16`·`/48`, and a global emergency key) charging every admitted attempt including successes, and a username staged-backoff counter (5 free failures, then 30s/1m/2m/5m/10m/30m/1h, reset on success, hard lock at 100) that advances only on a completed failed verification and never on a blocked one. Admission is an atomic `BEGIN IMMEDIATE` check-and-reserve in one WAL SQLite file under `STATE_DIR` shared across every port; rows are keyed by HMAC under a 0600 secret so raw usernames/IPs are never stored; lazy TTL prune + a row ceiling bound state (an absolute account lock is never evicted). Responses are a generic `429` with only a coarse minutes/hours band — never the firing scope, whether the account exists, attempts remaining, or a precise `Retry-After` — and known/unknown usernames are byte-identical. The client address is the socket peer only (`X-Forwarded-For` never trusted; SSH-tunnel/proxy coarsening documented). Algorithm choice recorded with evidence: token bucket over fixed-window (boundary burst), sliding-window-log (O(N) state — measured 2000 distinct-IP attempts collapse to ~404 rows via the coarse buckets), GCRA (equivalent), and ASN/reputation DB (external-dependency cost); decision latency p50=0.6ms/p95=1.2ms, ~23x cheaper than the 14ms PBKDF2 it gates. Setup mode and `YOLOMUX_TEST_AUTH_BYPASS` short-circuit before the limiter; cookie/share-token checks stay disjoint. Privacy-safe `login_throttle` aggregates surface in the admin System report; validated overrides load from `CONFIG_DIR/login-rate-limit.json` (a dedicated file, not `auth.yaml`, whose users-only parser would drop the section on its normalization rewrite), failing safe to defaults. Optional, OFF-by-default escalation (`yolomux_lib/login_escalation.py`): a harmless type-a-phrase decoy that never touches credentials/PBKDF2/cookies, and an expiring firewall DROP controller (argv-only `pf`/`nftables`, strict TTL, rule cap, trusted-CIDR exclusion, local list/clear) that fires only on volumetric network scopes, never a username lock. Reuse-not-copy: the WAL open/migrate/secret primitives moved to `atomic_file.py` (`open_wal_database`/`enable_wal_with_retry`/`begin_wal_migration`/`open_wal_session`/`load_or_create_secret_key`), shared with `ChatStore`/`ChatCursorCodec`. 55 deterministic fake-clock tests across `test_login_rate_limit.py`, `test_login_throttle_integration.py`, and `test_login_escalation.py` (bucket boundaries/refill with no window burst, progressive cooldown/non-extension/reset/100-lock, one-IP spray, many-IP one-username, `/24`+`/64` farm collapse and out-of-prefix isolation, v4-mapped keys, unknown/known parity, Basic parity, no-hash-on-block, prune/cardinality, concurrent no-overshoot, cross-process/restart persistence, coarse-band-never-understates, decoy/edge safety), all on isolated state/ports.
